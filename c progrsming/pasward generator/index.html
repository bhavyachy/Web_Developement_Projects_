Cryptographic Implementation Notes
Random Source (CSPRNG)
Uses window.crypto.getRandomValues() backed by the OS entropy pool instead of Math.random(), which is non-cryptographic and predictable.
Unbiased Rejection Sampling
Random indices are sampled using a bitmask/limit threshold (maxValid = floor(2^32 / N) * N) to eliminate modulo bias across arbitrary character pool sizes.
Fisher–Yates Shuffle
When strict class guarantees are enabled, mandatory class characters are inserted first and then permuted uniformly via Fisher–Yates with CSPRNG indices.
